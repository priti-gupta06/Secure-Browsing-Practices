# Secure-Browsing-Practices

## Overview
This project was completed as part of my Cyber Secur
ity internship track at Veda Technology. It focuses on creating a secure browsing checklist to help employees browse the internet safely and reduce common cybersecurity risks.

## Objectives
- Promote safe internet usage.
- Identify suspicious websites and phishing links.
- Understand the importance of HTTPS.
- Encourage secure downloads and regular browser updates.
- Review browser extensions for security risks.

## Checklist
- Verify HTTPS before sharing sensitive information.
- Avoid suspicious links and websites.
- Download files from trusted sources only.
- Keep browsers updated.
- Remove unnecessary or untrusted extensions.
- Use strong passwords and multi-factor authentication.
- Avoid sensitive transactions over unsecured public Wi-Fi.
- Never ignore browser security warnings.

Note : HTTPS encrypts communication between the browser and website, but it does not guarantee that the website itself is trustworthy.

## Tools Used
- Web Browser
- Google Docs
  
## Learning Outcomes
This project improved my understanding of secure browsing, phishing prevention, safe downloading, browser security, and online privacy.

## Conclusion
Secure browsing practices are an important part of cybersecurity. Following these guidelines helps reduce common online threats and supports safer internet usage.
